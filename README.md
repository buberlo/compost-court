# Compost Court

> Lead a parliament of rotting fruit until the worms accept your rule.

A turn-based strategy game where each food scrap becomes a citizen with a rot meter, voting weight, and tiny ambitions. You pass compost laws, bribe beetle lobbyists, and survive elections before the whole pile collapses into smelly anarchy.

## Features
- Rot meters for each scrap-citizen that change their party, power, and smell aura every turn
- Law drafting panel where you assign waste to worms, beetles, or the central pile
- Worm lobbyist AI that demands bribes and files motions against bad laws
- Election mode where citizens vote based on freshness, stink, and who feeds them

## Stack
- Phaser
- TypeScript
- Zustand
- Vite

## Getting started
```
npm install
npm run dev
```
